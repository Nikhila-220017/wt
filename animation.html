jQuery Animation Control Methods

1. Start Sequence

Queues 3 animations: move right → grow → fade out

2. stop()

Stops the current animation. Remaining queue still runs.

3. finish()

Jumps all animations (current + queued) to their final state instantly.

4. delay()

Pauses 1.5 seconds between two animations.

5. clearQueue()

Removes all pending animations from the queue. Current one finishes.

6. dequeue()

Manually triggers the next item in the queue.
