jQuery Attribute Methods

1. .attr() — Change Image Source

This method gets or sets an HTML attribute like src, href, class, etc.

2. .removeAttr() — Enable a Disabled Input

This method removes an attribute from an element completely.



3. .prop() — Check / Uncheck a Checkbox

This method gets or sets a DOM property like checked, disabled, selected.



4. .val() — Get / Set Input Value

This method gets or sets the value of a form input field.
