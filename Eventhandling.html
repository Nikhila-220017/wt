jQuery Event Handling Methods

A. Mouse Events

1. click()

Fires when the user clicks a button once.

2. dblclick()

Fires when the user double-clicks a button.

3. mouseenter()

Fires when the mouse enters the element area.

4. mouseleave()

Fires when the mouse leaves the element area.

5. hover()

Combines mouseenter + mouseleave in one method. Box changes color on hover.

Hover Over Me

6. mousedown()

Fires the moment the mouse button is pressed down.

Press Mouse Down

7. mouseup()

Fires the moment the mouse button is released.

B. Keyboard Events

Type inside the input box below to see all keyboard events fire.

8. keydown()

Fires when a key is pressed down (before character appears).

9. keypress()

Fires while a key is being pressed (character keys only).

10. keyup()

Fires when a key is released.

C. Form Events

11. focus() & 12. blur()

focus() fires when you click inside the field.
blur() fires when you click outside (leave the field).

13. change()

Fires when the value of an input or select changes (after leaving the field).

14. submit()

Fires when the form is submitted. We prevent the page from reloading.


D. General Event Methods

15. on()

on() attaches an event to an element. It is the recommended way to bind events in jQuery.

16. off()

off() removes a previously attached event. After clicking "Remove Event", the button stops working.
